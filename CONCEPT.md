# arcanitebrothers — concept

**Author:** Babuni.dev

A local browser admin console for the Morkahja game, bringing player moderation, server activity and game-content administration into one dashboard.

## Defining principle

The tool intentionally runs locally and uses a proxy for admin endpoints and separately hosted game data. Sensitive API keys belong in ignored local environment files, not public documentation.
