# arcanitebrothers — design evidence

**Author:** Babuni.dev

The tool intentionally runs locally and uses a proxy for admin endpoints and separately hosted game data. Sensitive API keys belong in ignored local environment files, not public documentation.

This is the position stated or embodied by current documentation; original discussion history is not inferred.

Test production/mock modes, moderation permissions, API failures and handling of admin keys locally. Do not claim access control is sufficient from the UI alone.
